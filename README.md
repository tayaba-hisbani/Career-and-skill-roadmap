# 🎯 AI Career & Skill Roadmap

An AI-powered career guidance application that helps university students identify suitable career directions, understand their skill gaps, create personalized learning roadmaps, and prepare for internships and entry-level jobs.

🔗 **Live Demo:** https://career-and-skill-roadmap.streamlit.app/

---

## 📌 Overview

University students often know the degree they are studying but are unsure about:

- Which career is suitable for them
- Which skills they need to develop
- What skills they should learn first
- Which projects they should build
- How to prepare for internships and jobs
- How to organize their learning around their available time

This application uses AI to analyze a student's profile and target career and generate a personalized career and skill-development roadmap.

---

## 💡 Problem

Students commonly face a gap between:

**University Education → Required Job Skills → Career Goal**

A student may know what career they want but may not know:

> "What should I learn first?"

> "Which skills am I missing?"

> "How much time should I spend learning?"

> "What projects should I build for my portfolio?"

This application attempts to provide a practical starting point.

---

## 🚀 Solution

The AI Career & Skill Roadmap application takes information about a student's:

- Degree
- University
- Current study level
- Interests
- Current skills
- Career goals
- Available learning time
- Target career/domain
- Current skill level
- Desired learning duration

The AI then generates a personalized roadmap.

---

## ✨ Features

### 👤 Student Profile

Students can enter:

- Degree
- University
- Semester/year
- Interests
- Current skills
- Career goals
- Available study time

---

### 🎯 Target Career Selection

Students can choose a target career/domain such as:

- Business Analyst
- Data Analyst
- Financial Analyst
- Marketing Analyst
- HR Analyst
- Product Manager
- Project Manager
- AI / Data
- Digital Marketing
- Finance
- Other/custom career

---

### 📊 Career Fit Estimate

The application provides an AI-estimated career fit score based on the student's:

- Education
- Interests
- Current skills
- Career goal
- Skill gaps
- Target career

The score is intended only as a planning indicator and is not a scientific career assessment.

---

### 🛠️ Skill Gap Analysis

The application identifies skills that the student may need to develop.

Each skill can include:

- Current level
- Target level
- Priority
- Reason for importance

Skills are categorized into:

🔴 High Priority  
🟡 Medium Priority  
🟢 Low Priority

---

### 🚀 Top 3 Priorities

Instead of giving students a long list of skills to learn, the application identifies the three most important starting priorities.

For each priority, the application provides:

- Skill
- Why it matters
- First step

---

### 📚 Personalized Learning Roadmap

The application creates a phased roadmap based on the student's selected learning duration.

Each phase can include:

- Timeframe
- Skills/topics
- Practical work
- Portfolio project
- Suggested study time

---

### 🗓️ Weekly Study Plan

The weekly plan is adapted according to the student's available study time.

For example:

```text
Available time: 5 hours/week

Monday    → Learning
Tuesday   → Practice
Wednesday → Learning
Thursday  → Project work
Friday    → Revision
Weekend   → Portfolio work
